# Примеры поручений для Формовода

Начните с чтения на своей тестовой веб-публикации. Для воспроизведения примеров с Excel нужны документы, содержащие соответствующие позиции. Файлы в этом каталоге подготовлены для учебных сценариев 1С:ERP.

## Справочник или открытый документ

> Открой справочник номенклатуры и скажи, какие колонки видны в списке.

> В открытом документе найди табличную часть с товарами. Перечисли первые три видимые позиции и их количества.

## Цены в заказе поставщику

В рабочем дубле открыли учебный заказ, два воркера ввели цены пяти позиций, проверяющий перечитал каждую цену. [Видео, 20 секунд](https://github.com/andromanpro/formovod/releases/download/v0.8.1/Formovod-SP-041-blockbuster.mp4)

Для повтора возьмите [спецификацию СП-041](<erp/Спецификация СП-041.xlsx>) и поместите её во входящую папку Формовода. По умолчанию это рабочий стол. Откройте учебный заказ с нужными артикулами.

> В заказе поставщику заполни цены пяти соответствующих позиций по спецификации СП‑041 в экселе на рабочем столе. Сопоставь позиции по артикулу, сверь каждую цену после ввода и оставь заказ открытым без записи.

## Пересчёт запасов

Возьмите [учебную ведомость](<erp/inventory/Ведомость инвентаризации.xlsx>) и откройте тестовую базу с соответствующим непроведённым пересчётом. Из корня репозитория можно запустить Формовод с отдельной папкой входящих файлов.

```powershell
.\Start-Formovod.cmd --inbox ".\examples\erp\inventory"
```

> Возьми ведомость инвентаризации. Найди пересчёт по номеру, дате и складу. Внеси в черновик факт по артикулу, характеристике и единице. Ноль учитывай. Обе строки дубля, неизвестный артикул и несовпадающую единицу пропусти. Перечитай результат. Оставь документ открытым без записи и проведения.

Для повторной проверки попросите сверить тот же черновик с той же ведомостью и оставить совпадающие количества как есть.
