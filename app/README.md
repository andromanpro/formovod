# Формовод в веб-клиенте 1С

Это отдельное расширение Chromium Manifest V3. Оно рисует курсоры и рамки
в прозрачном слое браузера. Геометрия рамок берётся из живых элементов формы.
Power Mode запускается от браузерного события ввода или от проверенного
изменения значения в числовом редакторе 1С после нажатия клавиши. Частицы
начинаются у введённого символа по положению каретки и метрикам шрифта.

## Одно окно с поручениями и отделом

Запустите `Start-Formovod.cmd` из корня проекта, выберите найденную или сохранённую публикацию и нажмите «Подключить». Для прямого подключения используйте `--url`. В правой панели введите поручение и нажмите «Отправить» или Ctrl+Enter.
По умолчанию поручение ведёт Codex через текущий вход в CLI. В **Настройки → Модели, роли и прокси** открывается отдельная вкладка этого же окна. Для каждой из пяти ролей можно выбрать поставщика и идентификатор модели. «Как у оркестратора» сохраняет обработку в текущем ходе. Явное назначение запускает отдельный ход специалиста на общей форме и отражается в журнале. Архитектор осматривает форму и составляет план, воркеры получают ввод, проверяющий получает чтение и сверку.

- **Codex** получает каталог из локального CLI. Пустой идентификатор у Codex использует основную модель пульта.
- **GLM по подписке** использует установленный DSH, его ACP-профиль и вход Z.ai Coding Plan. Выберите профиль и нажмите «Загрузить каталог». При автоматическом выборе проверяются agent-office, legion-rooms и acp. Перед отправкой DSH подтверждает пару zai-coding-plan и выбранную модель.
- **OpenRouter** принимает ключ через настройки или переменную `OPENROUTER_API_KEY`. Сохранённый в профиле ключ зашифрован Windows DPAPI. Каталог показывает модели с поддержкой инструментов. Поручение и результаты назначенных инструментов получает выбранная модель, стоимость определяется её тарифом.
- **Прокси для моделей** действует при получении каталогов и при выполнении поручений. Доступны системный маршрут, прямое соединение и HTTP(S)-прокси с указанным портом. Ручной адрес вводится без учётных данных. Сеанс 1С и локальная диктовка используют собственное подключение.

Назначения хранятся рядом с настройками пульта в `settings.models.json`. Для другого пути `--settings` используется его имя с окончанием `.models.json`.

В отделе пять персонажей. Раскройте карточку оркестратора или архитектора, чтобы увидеть его за пультом. Два воркера и проверяющий
выходят при первом действии, назначенном каждому в поручении. Между шагами работник остаётся на форме
и идёт к следующей цели с места предыдущего действия. При вводе в таблицу свободный проверяющий
подходит к первой редактируемой строке. После перечитывания он отмечает результат сверки, пока воркер
может перейти к следующей строке. При ожидании около трёх секунд воркер опускает кувалду и закуривает.
Следующее действие прерывает перекур.
После окончания поручения участники возвращаются в свои домики. Регулятор скорости и пауза управляют движением на форме и в открытых карточках. Маршруты и линии к полям по умолчанию скрыты. Их включает флажок «Показывать линии от работников к целям».
Проверка с ожидаемым значением
показывает результат после перечитывания поля 1С.

Для другого веб-клиента запустите `visual_mcp.py --url URL --panel --interactive`.
Для подключения из внешнего MCP-клиента используйте `--panel` и откройте форму инструментом `open_1c`.
Пульт обращается к инструментам той же сессии. В этом режиме доступны `list_workbooks` и `read_workbook`
для книг .xlsx с рабочего стола. Параметр `--inbox` выбирает другой каталог. Для Excel нужен пакет `openpyxl`.
Микрофон в панели принимает одно голосовое поручение. В настройках видны используемый распознаватель и флажок
«Отправлять после окончания диктовки». По умолчанию окончание диктовки отправляет распознанный текст один раз. Отключите флажок для проверки текста и ручной отправки. Пауза пульта
или ошибка распознавания оставляет черновик в поле. После подтверждения приёма поле освобождается для
следующей команды. Текст, который оператор успел набрать за время отправки, сохраняется.

В разделе **Настройки → Распознавание речи** выберите автоматический режим, локальный Whisper, службу браузера или диктовку Windows. Для Whisper выберите Tiny, Base или Small, язык и длительность тишины, завершающей запись. Кнопка **Скачать и настроить Whisper** устанавливает локальный движок и выбранные веса. Первая установка требует интернета. Окончание фразы можно также обозначить повторным нажатием на микрофон.

Движок работает на CPU в отдельном Python 3.12 в `%LOCALAPPDATA%/Formovod/voice`. Установка использует PyPI и Hugging Face, а при отсутствии Python 3.12 загружает управляемый интерпретатор через uv. Для ранее настроенного окружения поддерживается `FORMOVOD_VOICE_PYTHON`. Звук передаётся локальному процессу в памяти. Скачанная модель распознаёт речь офлайн. Диктовка Windows вызывается сочетанием Win+H в поле поручения.

В свободном управлении каждое принятое поручение получает отдельный локальный JSONL в
`%APPDATA%/Formovod/logs` (при `--settings` — в `logs` рядом с файлом настроек). Путь виден
в настройках панели. Кнопка «Журнал» открывает просмотрщик в соседней вкладке. С версии 0.5
сохраняются адрес базы, текст поручения, способ ввода, модель, время, параметры и структурированный результат
вызовов инструментов, ошибки и итог. Запрошенные через screenshot_1c изображения хранятся рядом с JSONL
и открываются в событии вызова. Звук диктовки обрабатывается в памяти. Для внешнего stdio-клиента
записываются вызовы с источником mcp. Внутренний текст переписки внешнего клиента остаётся у этого клиента.

## Подключение к модели

Укажите `--brigade`, чтобы открыть пульт «Формовода» рядом с настоящей
формой 1С в том же окне Chromium. Пульт показывает три роли, маршруты
к видимым элементам, переключатель «Бригада / Курсоры», скорость эффектов
и приостановку правок. Пауза блокирует новые изменения. Чтение доступно,
уже начатое действие заканчивается. Скорость влияет на эффекты слоя.

`visual_mcp.py` — самостоятельный MCP-сервер для веб-клиента. Вызов `open_1c`
открывает видимое окно Chromium в отдельном временном профиле. Расширение
загружается при запуске браузера. Параметр `--record-dir` включает запись вкладки
с уже отрисованными эффектами. На компьютере нужны Python, MCP SDK,
Playwright и Chromium for Testing. Проверено с Python 3.14, MCP SDK 1.26.0
и Playwright 1.58.0. Для первого запуска можно установить их командами
из каталога с распакованным MCP.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

Возьмите команду и аргументы из [шаблона конфигурации](../examples/mcp/formovod.toml)
для своего MCP-клиента. Команды установки выполняются из корня проекта. При распаковке в другой каталог обновите `cwd` и путь к интерпретатору в TOML.
Если Chromium установлен через Playwright, аргумент `--chromium` можно убрать.
Для другой учебной публикации задайте `--url`.
Вход выполняется в окне браузера либо по настройкам `ONEC_VISUAL_USER` и `ONEC_VISUAL_PASSWORD`
из окружения процесса MCP для явно заданного начального адреса. При переключении на другую базу
используется её собственная авторизация в управляемом браузере. Кнопка с названием базы позволяет
выбрать сохранённое подключение или добавить адрес. Поручение выполняется с правами вошедшего оператора.

Для показа во внутреннем браузере Codex добавьте в аргументы `--headless` и
`--preview`. `open_1c` вернёт `preview_url`. Откройте этот адрес в панели Codex
как локальную страницу. На ней в реальном времени видна та же вкладка 1С с
курсорами, рамками, галочками и Power Mode. Команды вводятся через инструменты
MCP. Адрес показа действует на этом компьютере до `close_1c` или остановки MCP.

Для локальной рабочей области «Формовода» укажите `--workspace`. В ответе
`open_1c` появится `workspace_url`. Слева видна вкладка 1С, справа текущие
действия ролей и последние результаты. Нажмите карточку роли, чтобы связать её
линией с видимым полем. Линия убирается, если поле ушло с экрана.
Наведение курсора и ввод показаны как разные действия. Статус «Совпало»
появляется после чтения поля с ожидаемым значением.

«Приостановить правки» останавливает новые команды открытия, щелчка,
нажатия клавиш и ввода. Уже начатый набор заканчивается. Чтение и сверка
доступны на паузе. Управление указателем и клавиатурой из страницы показа
не передаётся в 1С. Для самостоятельной работы используйте видимое окно
Chromium, запущенное без `--headless`.

| Инструмент | Действие модели |
|---|---|
| `open_1c` | Открыть публикацию или внутреннюю навигационную ссылку |
| `inspect_1c` | Прочитать активную вкладку, распознанные диалоги, фокус и видимые элементы. Для поиска используйте `query`, `kind` и `offset`. В таблицах доступны колонки и границы видимого диапазона строк |
| `inspect_at_1c` | Найти распознанный элемент в точке на полном снимке. Возвращает `ref`, подпись и положение |
| `mouse_1c` | Щелчок, двойной или правый щелчок, наведение по координатам полного снимка |
| `scroll_1c` | Прокрутить форму колёсиком над элементом или точкой. Возвращает видимые таблицы после прокрутки |
| `click_1c`, `press_1c` | Щёлкнуть элемент или нажать клавишу 1С |
| `point_1c` | Переместить курсор роли к элементу и выделить до восьми связанных элементов пунктиром |
| `type_1c` | Напечатать символы по одному в открытом редакторе. `actor` задаёт курсор, `delay_ms` задаёт паузу между символами |
| `read_1c` | Прочитать значение. С параметром `expected` сравнить его с заданным и показать галочку или расхождение прямо на поле |
| `screenshot_1c` | Посмотреть текущую форму |
| `close_1c` | Закрыть браузер и получить запись, если она была запрошена |

Для выбора команды сначала найдите её по подписи и используйте `ref`.
У полей проверяйте тип, доступность и текущие значения. После щелчка или смены
вкладки перечитайте состояние. Если элемент без подписи, возьмите свежий
`screenshot_1c`, вызовите `inspect_at_1c` и по возможности используйте
возвращённый `ref`. При необходимости `mouse_1c` работает в координатах
исходного снимка, даже если элемент рисуется в canvas. `point_1c` рисует курсор,
для показа подсказки используйте `mouse_1c` с `action: "hover"`.
После прокрутки сверяйте `firstVisibleRow` и `lastVisibleRow`. В таблицах
с виртуальной прокруткой `rowIndex` может обозначать экранную позицию.
Обновляйте `ref` после перехода, прокрутки или перестройки формы. Если
экранная ячейка теперь относится к другой строке, старый `ref` отклоняется.

Дайте модели обычное поручение в чате. Например, попросите создать новое учебное
поступление, внести товары из списка и сверить их наименования, количества и цены
с исходными данными. Модель получает элементы из текущей формы и выбирает дальнейшие
вызовы.

Роли `price` и `quote` могут по очереди вводить цены разными курсорами.
Для номенклатуры, количества, ГТД, контрагента и договора есть роли
`product`, `quantity`, `gtd`, `counterparty` и `contract`.
В `point_1c` передайте `ref` текущей ячейки и `related_refs` ячеек,
намеченных для этой роли. Последующие щелчки и ввод сохраняют эти рамки.
Пустой `related_refs` убирает пунктирные рамки для роли. Во время ввода другим
курсор можно перемещать и отмечать ячейки без смены фокуса. Изменения в 1С
выполняются по очереди через активный редактор. Power Mode принадлежит роли,
переданной в `type_1c`.

`read_1c` с ролью `check` может сверять уже заполненную ячейку одновременно с вводом
в другой. Сверка сохраняет регистр и учитывает отображаемый формат 1С. Например,
для цены передайте `expected: "2 375,00"`. Пробелы и неразрывные пробелы эквивалентны.
При перерисовке 1С метка возвращается, если совпадают таблица, строка,
идентифицирующие колонки и проверенное значение. Вне видимой области метка скрыта.
При изменении строки или значения сравнение нужно выполнить заново.
При расхождении `read_1c` возвращает `matches: false` и фактическое значение.

Power Mode усиливает ввод короткой дрожью таблицы, вспышкой, вылетом крупного
символа и цветными частицами. Импульс щелчка начинается там, куда попал указатель.

## Расширение вне MCP

Распакуйте комплект и укажите папку `extension` в окне `chrome://extensions`
через **«Режим разработчика» → «Загрузить распакованное расширение»**.
На локальном маршруте `/live/` слой подключается автоматически. На другой
публикации 1С нажмите кнопку расширения в открытой вкладке.

Чтобы пометить поле, исполнитель передаёт событие `testpilot:overlay` на странице
веб-клиента. Селектор должен указывать на элемент текущей формы.

```javascript
document.dispatchEvent(new CustomEvent("testpilot:overlay", {
  detail: {
    kind: "mark",
    actor: "check",
    selector: 'input[id$="_МестоХранения_i0"]',
    note: "склад подтверждён",
    done: true
  }
}));
```

Событие принимает те же роли, что и инструменты MCP, включая `entry` и `check`.
Уберите метку событием
с `kind: "clear"` и именем роли. Для набора текста расширение само подсвечивает активное
поле и запускает эффект от фактического ввода. События управляют только показом.
Браузерный исполнитель MCP использует Playwright. Такой же контракт можно
вызывать из Vanessa или другого браузерного исполнителя.
