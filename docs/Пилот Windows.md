# Формовод для Windows. Первый запуск

Формовод открывает веб-клиент 1С и принимает поручения в правой панели. Для пилота нужны Windows x64, Python 3.14 с командой `py -3.14`, веб-публикация 1С и ваш обычный доступ к ней. Исходная схема ролей использует Codex CLI с выполненным входом. Подключения GLM и OpenRouter настраиваются в пульте. Для установки Python-пакетов и Chromium нужен доступ к источникам пакетов. Распакуйте архив в доступную для записи папку и откройте в ней PowerShell.

**Установка и проверка.** Подставьте адрес своей публикации и существующую папку входящих файлов.

```powershell
.\Install-Formovod.cmd
.\Start-Formovod.cmd --check --url "https://your-server/erp/ru_RU/" --inbox "D:\Входящие"
```

Проверка открывает публикацию в отдельном фоновом браузере, ждёт появления пульта, запрашивает каталог моделей и проверяет чтение входящей папки. Локальное распознавание речи проверяется отдельно. Если оно недоступно, поручения можно печатать.

**Работа в панели.**

```powershell
.\Start-Formovod.cmd --manual-login --url "https://your-server/erp/ru_RU/" --inbox "D:\Входящие"
```

Войдите в 1С под своей обычной учётной записью. Формовод будет действовать с вашими правами. В настройках выберите модель. Введите «Открой справочник номенклатуры» и нажмите «Отправить». Сверьте название вкладки и содержимое списка. В **Настройки → Распознавание речи** выберите «Whisper на компьютере», модель и язык, нажмите «Скачать и настроить Whisper». После установки доступна офлайн-диктовка. Время тишины и отправку после диктовки можно изменить там же.

**Модели бригады.** В настройках нажмите «Модели, роли и прокси». Для обычной работы оставьте Codex оркестратору и «Как у оркестратора» остальным. Чтобы передать работу специалисту, выберите для его роли поставщика, загрузите каталог и укажите модель. GLM использует подписочный профиль DSH с Z.ai Coding Plan, OpenRouter использует ключ API. Сохранение применяется со следующего поручения. Прокси можно оставить системным или указать адрес с портом. По умолчанию локальная и браузерная диктовка отправляют фразу сразу после распознавания. Для ручной отправки снимите флажок в настройках речи.

Обычный запуск `.\Start-Formovod.cmd` открывает выбор базы. В форме видны публикации Apache, IIS, веб-подключения из списка 1С и сохранённые адреса. Выберите доступную публикацию и нажмите **Подключить**. Если адреса нет, раскройте **Указать адрес вручную**. В открытом пульте список обновляется через **База → Обновить список публикаций**. После успешного подключения адрес сохранится в профиле Windows. Предыдущая база с открытыми документами остаётся в своей вкладке. Команда с явным `--url` подключает указанную базу напрямую.

Для проверки ввода используйте согласованный учебный черновик. Попросите изменить два количества по очереди и перечитать каждое. После первой сверки нажмите **Остановить поручение**. Прочитайте итог в панели и проверьте вторую строку. Уже переданное в 1С действие может завершиться. При остановке во время набора в редакторе может остаться часть значения. Исправьте его или отмените редактирование штатной командой 1С. Остановка оставляет окно открытым. Для продолжения отправьте новое поручение. Обычная кнопка **Пауза** сохраняет прежнее назначение.

Кнопка **Журнал** рядом с выбором базы открывает историю в соседней вкладке. Выберите поручение по времени, базе и тексту. Нажатие на строку показывает подробности события. Новые события появляются во время работы. В журнал попадают в том числе прочитанные строки Excel и поля 1С. Запрошенные моделью снимки доступны в событиях screenshot_1c. Эти файлы хранятся локально, по умолчанию в `%APPDATA%\Formovod\logs`. Выбранная модель получает текст поручения и результаты вызовов инструментов. Права на операции с документами задаёт сама 1С.

**Подключение внешнего MCP-клиента.** Команда выведет блок TOML с местными путями. Добавьте его в конфигурацию своего клиента.

```powershell
.\Start-Formovod.cmd --print-mcp --manual-login --url "https://your-server/erp/ru_RU/" --inbox "D:\Входящие"
```
